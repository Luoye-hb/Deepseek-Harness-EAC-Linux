Date: 2026-08-22

## Scope

This is the stage 0 baseline required before changing the desktop shell. The
worktree was already dirty before the migration branch was created. Existing
plugin and upstream-sync changes were preserved and are not attributed to this
migration.

The baseline is therefore a diagnostic record, not a claim that the current
worktree is a clean release commit.

   TypeScript source.

These failures must remain visible until fixed or explicitly accepted. They
must not be counted as Tauri migration regressions.

## Startup Probe

An isolated Electron probe used:

- `DSH_HOME=/tmp/dsh-tauri-baseline-escalated.G5cLci/dsh-home`
- `DSH_DESKTOP_USERDATA=/tmp/dsh-tauri-baseline-escalated.G5cLci/userdata`
- `DSH_DESKTOP_SKIP_CLIENT_UPDATE=1`
- `npm start -- --no-sandbox`

The probe reached the application boot path:

- boot log at `08:41:14.317` local time;
- plugin wizard opened at `08:41:14.344`;
- preview server started at
  `http://127.0.0.1:35951` at `08:41:14.348`.

The fresh-user path stopped before `dsh web` HTTP readiness because the plugin
wizard was still open. The process was then terminated by the 25-second probe
timeout (`status 124`), so this is not yet a graceful-exit pass.

An in-sandbox attempt failed earlier inside Chromium with
`sandbox_host_linux.cc: Operation not permitted`; that failure was caused by
the execution sandbox and did not reach application boot.
